# 🍳 요리 레시피

유튜브·만개의레시피 링크를 모아 두고 바로 여는 나만의 레시피 앱 (갤럭시용 PWA).

- 링크 추가: 유튜브/만개의레시피에서 **공유 → 요리 레시피**, 또는 ＋ 버튼
- 삼성 노트 가져오기: 노트 전체를 복사해 붙여넣으면 "링크 다음 줄 = 요리 이름"으로 일괄 등록
- 썸네일·제목 자동, 분류 자동 추측, 검색, 즐겨찾기, 🎲 오늘 뭐 먹지?
- 데이터는 휴대폰 안(localStorage)에만 저장 → 메뉴에서 백업 파일 만들기/복원

## 요리 모드 · 음성 명령
카드를 누르면 앱 안 요리 모드(화면 꺼짐 방지)로 열린다. 기본은 "한 단계씩 크게" 보기(재료 → 1단계 → …, 아래 큰 이전/다음 버튼),
글씨 크기는 가−/가+ 로 5단계 조절(기억됨). 가로로 세우면 재료·순서 2단. 🎤 를 켜고 짧게 말한다.
- "다음" "이전" "7번으로 이동해 줘"/"세 번째 단계" "끝으로"(마지막 단계) "맨 위로" "재료 화면으로" "읽어 줘" / "내려" "올려" "맨 위로" "맨 아래" "전체 보기" / "크게" "작게"
- 유튜브: "재생" "멈춰" "뒤로" "앞으로"(10초) / "닫아" "그만 들어"
- 웹 레시피는 페이지의 schema.org Recipe(JSON-LD)에서 재료·순서를 뽑는다(공개 프록시 allorigins → 실패 시 r.jina.ai 본문). HTML 에 JSON-LD 가 없으면 만개의레시피 화면 구조 → 리더 본문 텍스트 정리 순으로 시도.
  가져오기 직후·앱 시작 시 뒤에서 미리 받아 저장하므로(실패한 링크는 6시간 뒤 재시도) 요리 모드는 인터넷 없이도 바로 열린다.

## 유튜브 레시피 정리 (API 키 없이)
- 영상 페이지(공개 중계 서비스 경유)의 ytInitialPlayerResponse·ytInitialData 를 읽는다.
- 설명란에 [재료]/[만드는 법]이 있으면 카드로, 챕터(유튜버 챕터 → 설명란 목차 → 유튜브 자동 챕터 순)는 단계 제목+영상 위치로.
- 인트로·구독 인사·제품 추천 챕터, 설명란의 링크·해시태그·쿠팡 파트너스 문구는 걸러낸다.
- 단계를 넘기면(버튼·음성 "3번") 영상이 그 장면으로 이동, 재생 중에는 지금 장면의 단계를 자동으로 따라간다.
- 비공식 방식이라 유튜브 구조가 바뀌면 깨질 수 있다. 정리할 글·챕터가 없는 영상은 영상 + 설명 메모만.

## 스텝별 타이머
- 단계 문장 속 시간("2분", "1분 30초", "2~3분"→짧은 쪽)을 찾아 ⏱ 버튼으로 보여준다. 헤더 ⏱ 로 직접 맞추기(30초~30분 빠른 선택, "직접 설정" → 분·초 시계 다이얼 팝업).
- 여러 개 동시 실행, 종료 시각으로 저장해 앱을 껐다 켜도 이어진다. 목록 화면 아래에도 남은 시간이 보인다.
- 끝나면 시스템 알림(서비스워커 showNotification, 진동·잠금화면 표시) + 화면 전체 알람 + 알람음·진동·음성 안내. "알았어"/확인으로 끈다.
- 음성: "타이머 시작"(지금 단계 시간) "3분 타이머" "타이머 꺼" "알았어".
- 한계: 서버 푸시가 아니라 앱이 살아 있을 때 울리는 로컬 알림이다. 앱을 완전히 닫거나 오래 백그라운드에 두면 늦게 울릴 수 있다(다시 열면 즉시 알림).

삼성 노트에서 글을 선택해 **공유 → 요리 레시피** 하면 링크가 여러 개일 때 가져오기 화면이 미리 채워져 열린다.

## 음성으로 열기 (빅스비)
1. 갤럭시 크롬에서 배포 주소 열기 → ⋮ → **설치 및 바로가기 만들기 → 설치** (또는 앱 상단 📲 앱 설치 버튼)
2. "하이 빅스비, 요리 레시피 열어줘"
3. 빅스비 → 설정 → **빠른 명령어**: `요리를 시작해 볼게` → `요리 레시피 열어줘`

딥링크: `?q=멸치볶음` (검색·하나면 바로 띄움), `?random=1` (랜덤 추천), `?add=1` (추가 화면)

## 개발
```bash
npm install
npm run dev     # 개발 서버
npm test        # 단위 테스트
npm run build   # dist/ 생성
```
