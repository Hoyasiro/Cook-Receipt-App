# 🍳 요리 레시피

유튜브·만개의레시피 링크를 모아 두고 바로 여는 나만의 레시피 앱 (갤럭시용 PWA).

- 링크 추가: 유튜브/만개의레시피에서 **공유 → 요리 레시피**, 또는 ＋ 버튼
- 삼성 노트 가져오기: 노트 전체를 복사해 붙여넣으면 "링크 다음 줄 = 요리 이름"으로 일괄 등록
- 썸네일·제목 자동, 분류 자동 추측, 검색, 즐겨찾기, 🎲 오늘 뭐 먹지?
- 데이터는 휴대폰 안(localStorage)에만 저장 → 메뉴에서 백업 파일 만들기/복원

## 📲 앱 설치 (PWA)
이 앱은 앱스토어 없이 웹 주소에서 바로 설치하는 **PWA(설치형 웹앱)** 다. 한 번 설치하면 홈 화면 아이콘으로 열리고,
주소창 없이 전체 화면으로 뜨며, 인터넷이 없어도 열린다.

- 설치 주소: **https://hansik-receipt.github.io/Cook-Receipt-App/** (직접 배포했다면 `https://<계정>.github.io/<저장소 이름>/`)
- 반드시 위의 **https 배포 주소**에서 설치한다. `npm run dev` 의 `http://192.168.x.x` 같은 주소는 서비스워커가 동작하지 않아 설치되지 않는다.

### 어떤 브라우저로 설치해야 하나
| 기기 · 브라우저 | 설치 | 공유 → 요리 레시피 | 타이머 알림 | 길게 누르기 메뉴 |
|---|:-:|:-:|:-:|:-:|
| 안드로이드(갤럭시) **크롬** — 권장 | ✅ | ✅ | ✅ | ✅ |
| 안드로이드 삼성 인터넷 | ✅ | ❌ | ✅ | ❌ |
| 아이폰·아이패드 사파리 | ✅ (홈 화면에 추가) | ❌ | iOS 16.4 이상 | ❌ |
| PC 크롬 · 엣지 | ✅ | ❌ | ✅ | ✅ |

> 유튜브·만개의레시피·삼성 노트의 **공유 → 요리 레시피** 는 안드로이드 **크롬**으로 설치했을 때만 나타난다.
> 삼성 인터넷으로 이미 설치했다면 지우고 크롬으로 다시 설치한다.

### 갤럭시(안드로이드) 크롬 — 권장
1. **크롬**을 열고 설치 주소에 접속한다. (카톡 등에서 링크를 눌러 앱 안 브라우저로 열렸다면 ⋮ → **다른 브라우저로 열기 → Chrome**)
2. 다음 중 하나로 설치한다.
   - 앱 화면 위쪽의 **📲 앱 설치** 버튼 → 뜨는 창에서 **설치**
   - 또는 크롬 오른쪽 위 **⋮** → **설치 및 바로가기 만들기**(크롬 버전에 따라 **앱 설치** / **홈 화면에 추가**) → **설치**
   - 화면 아래에 "요리 레시피 설치" 배너가 뜨면 그걸 눌러도 된다.
3. 1~2분 안에 홈 화면과 앱스 화면에 **요리 레시피** 아이콘이 생긴다. 이 아이콘으로 연다.
   (설치가 끝나면 앱 안에 "설치했어요!" 안내가 뜨고, 📲 버튼은 사라진다.)
4. 설치 확인: 아이콘으로 열었을 때 **주소창이 없으면** 정상 설치다. 설정 → 애플리케이션 목록에도 "요리 레시피"가 보인다.

> 📲 버튼을 눌렀는데 설치 창 대신 안내만 뜨면, 크롬이 아직 설치 준비가 안 된 것이다(첫 접속 직후·이미 설치됨·삼성 인터넷 등).
> 페이지를 한 번 새로고침하거나 ⋮ 메뉴로 설치한다.

### 갤럭시 삼성 인터넷
주소창의 **⬇(설치) 아이콘** 또는 메뉴 **≡ → 현재 페이지 추가 → 홈 화면**. 앱처럼 열리지만 **공유 대상**과 **길게 누르기 메뉴**는 지원되지 않는다.

### 아이폰 · 아이패드 (사파리)
1. **사파리**로 설치 주소를 연다. (iOS 16.4 이상은 크롬에서도 가능)
2. 아래쪽(아이패드는 위쪽) **공유 버튼 □↑** → **홈 화면에 추가** → 이름 확인 → **추가**
3. 홈 화면의 **요리 레시피** 아이콘으로 연다.

아이폰은 "공유 → 요리 레시피"가 없으므로 링크는 앱 안 **＋** 버튼으로 붙여넣는다.
타이머 시스템 알림은 iOS 16.4 이상에서 **홈 화면에 추가한 앱**으로 열었을 때만 동작한다.

### PC (크롬 · 엣지)
주소창 오른쪽의 **설치 아이콘(모니터+⬇)** → **설치**. 또는 ⋮ → **전송, 저장, 공유 → 페이지를 앱으로 설치**(엣지: … → **앱 → 이 사이트를 앱으로 설치**).
시작 메뉴/독에서 별도 창으로 열린다.

### 설치 뒤 해 두면 좋은 것
- **알림 허용**: 처음 타이머를 시작할 때 알림 권한을 묻는다 → **허용**. 놓쳤다면 휴대폰 설정 → 애플리케이션 → 요리 레시피(또는 Chrome) → 알림 → 허용.
- **배터리 최적화 제외**(갤럭시): 설정 → 애플리케이션 → **Chrome** → 배터리 → **제한 없음**. 백그라운드에서 타이머 알림이 늦게 울리는 것을 줄여 준다.
- **홈 화면 아이콘 길게 누르기**: "레시피 추가" / "오늘 뭐 먹지?" 바로가기가 나온다 (크롬 설치 시).
- **오프라인**: 한 번 열어 두면 앱 화면과 이미 받아 둔 레시피·썸네일은 인터넷 없이도 열린다.
- **음성으로 열기**: 아래 [음성으로 열기 (빅스비)](#음성으로-열기-빅스비) 참고.

### 업데이트
따로 할 일 없다. 앱을 열거나 다시 화면에 띄울 때(그리고 켜 둔 동안 30분마다) 새 버전을 확인해 자동으로 바뀐다.
요리 모드가 열려 있으면 화면이 갑자기 바뀌지 않도록 닫을 때까지 미룬다. 현재 버전(빌드 시각·커밋)은 앱 메뉴에서 볼 수 있다.

### 삭제 · 기기 변경
- 삭제: 홈 화면 아이콘 길게 누르기 → **삭제/제거** (PC: 앱 창 ⋮ → **제거**).
- 레시피는 **이 기기의 이 브라우저 안(localStorage)** 에만 저장된다. 앱을 지우거나 브라우저 데이터를 지우기 전, 다른 브라우저·기기로 옮기기 전에는
  꼭 메뉴의 **백업 · 복원 → 백업 파일 만들기** 로 저장해 두고, 새로 설치한 뒤 **백업에서 복원** 한다.

### 설치가 안 될 때
| 증상 | 해결 |
|---|---|
| ⋮ 메뉴에 "설치" 항목이 없고 "홈 화면에 추가"만 있다 | 페이지를 새로고침하고 10초쯤 둔 뒤 다시 본다. 그래도 없으면 크롬을 최신으로 업데이트한다. |
| 이미 설치했다는데 아이콘이 안 보인다 | 앱스 화면(전체 앱 목록)을 확인한다. 홈 화면 설정의 "새 앱을 홈 화면에 추가"가 꺼져 있으면 홈에는 안 생긴다. |
| 공유 목록에 "요리 레시피"가 없다 | 크롬으로 설치했는지 확인한다(삼성 인터넷·아이폰은 미지원). 설치 직후엔 휴대폰을 한 번 재시작하면 목록에 나타나는 경우가 있다. 공유 창의 **더보기/편집**에서 숨겨져 있지 않은지도 본다. |
| 아이콘으로 열었는데 주소창이 보인다 | 설치가 아니라 바로가기로 추가된 것이다. 지우고 ⋮ → **설치**로 다시 설치한다. |
| 예전 화면이 계속 보인다 | 앱을 완전히 닫았다가 다시 연다. 그래도 그대로면 인터넷 연결 상태에서 한 번 더 연다. |

## 요리 모드 · 음성 명령
카드를 누르면 앱 안 요리 모드(화면 꺼짐 방지)로 열린다. 기본은 "한 단계씩 크게" 보기(재료 → 1단계 → …, 아래 큰 이전/다음 버튼),
글씨 크기는 가−/가+ 로 5단계 조절(기억됨). 가로로 세우면 재료·순서 2단. 🎤 를 켜고 짧게 말한다.
- "다음" "이전" "7번으로 이동해 줘"/"세 번째 단계" "끝으로"(마지막 단계) "맨 위로" "재료 화면으로" "읽어 줘" / "내려" "올려" "맨 위로" "맨 아래" "전체 보기" / "크게" "작게"
- 유튜브: "재생" "멈춰" "뒤로" "앞으로"(10초) / "닫아" "그만 들어"
- 웹 레시피는 페이지의 schema.org Recipe(JSON-LD)에서 재료·순서를 뽑는다(공개 프록시 allorigins → 실패 시 r.jina.ai 본문). HTML 에 JSON-LD 가 없으면 만개의레시피 화면 구조 → 리더 본문 텍스트 정리 순으로 시도.
  가져오기 직후·앱 시작 시 뒤에서 미리 받아 저장하므로(실패한 링크는 6시간 뒤 재시도) 요리 모드는 인터넷 없이도 바로 열린다.

## 스텝별 타이머
- 단계 문장 속 시간("2분", "1분 30초", "2~3분"→짧은 쪽)을 찾아 ⏱ 버튼으로 보여준다. 헤더 ⏱ 로 직접 맞추기(30초~30분 빠른 선택, "직접 설정" → 분·초 시계 다이얼 팝업).
- 여러 개 동시 실행, 종료 시각으로 저장해 앱을 껐다 켜도 이어진다. 목록 화면 아래에도 남은 시간이 보인다.
- 끝나면 시스템 알림(서비스워커 showNotification, 진동·잠금화면 표시) + 화면 전체 알람 + 알람음·진동·음성 안내. "알았어"/확인으로 끈다.
- 음성: "타이머 시작"(지금 단계 시간) "3분 타이머" "타이머 꺼" "알았어".
- 한계: 서버 푸시가 아니라 앱이 살아 있을 때 울리는 로컬 알림이다. 앱을 완전히 닫거나 오래 백그라운드에 두면 늦게 울릴 수 있다(다시 열면 즉시 알림).

삼성 노트에서 글을 선택해 **공유 → 요리 레시피** 하면 링크가 여러 개일 때 가져오기 화면이 미리 채워져 열린다.

## 음성으로 열기 (빅스비)
1. 먼저 갤럭시 **크롬**으로 앱을 설치한다 → [앱 설치 (PWA)](#-앱-설치-pwa)
2. "하이 빅스비, 요리 레시피 열어줘"
3. 빅스비 → 설정 → **빠른 명령어**: `요리를 시작해 볼게` → `요리 레시피 열어줘`

딥링크: `?q=멸치볶음` (검색·하나면 바로 띄움), `?random=1` (랜덤 추천), `?add=1` (추가 화면)
